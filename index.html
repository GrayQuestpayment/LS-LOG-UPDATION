Ye tool kya karta hai?

Har LS pay ID ko dump mein dhoondhta hai. Ek pay ID ke against EMI aur charges dono rows ho sakti hain — tool sirf woh row rakhta hai jiska Amount Received from Customer LS ke amount se exactly match karta hai (charges auto-strip). Phir dump format mein sheet banata hai: Payment Type + Amount Settled to Lender bhardeta hai, aur base file de to Bank/Beneficiary/A-c/IFSC bhi (lender ke naam se). Settlement UTR aur Settlement Date khaali (yellow) chhodta hai — woh aapke transfer records se aati hai. Koi formula nahi — direct upload-safe.
